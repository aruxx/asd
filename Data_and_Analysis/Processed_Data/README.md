# Processed Data Pipeline

Processed datasets are generated after applying the cleansing, normalization, and validation routines outlined in `SMA_Analysis/Methodology.md`. Each processed artifact includes:

1. **Source Traceability:** Original feed identifiers, timestamps, and broker metadata.
2. **Normalization Log:** Timezone conversions, unit harmonization, and field mappings.
3. **Quality Flags:** Indicators for imputed values, outlier handling, and duplicate collapse decisions.
4. **SMA Readiness:** Rolling sums and cached SMA windows required for rapid recomputation across outfits and timeframes.

## Directory Layout
- `./instruments/` – Instrument-specific datasets keyed by ticker.
- `./sessions/` – Institutional vs extended session breakdowns.
- `./signals/` – Serialized SMA crossover events, frequency studies, and enforcement triggers.

> **Note:** This directory intentionally ships without raw data snapshots inside the public repository. Populate it with processed outputs generated by your private ingestion pipelines, or use the `Tools_and_Scripts` utilities to create sanitized samples suitable for sharing. EOF
