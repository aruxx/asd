# Overview

Simple Moving Average outfits dictate when and where the largest equity managers direct liquidity. Every equity, volatility product, and macro proxy aligns with pre-selected SMA bands, ensuring that capital responds to deterministic triggers rather than discretionary sentiment. This repository captures the organizations of those outfits and the systems they support.

Topics covered in this overview:

1. **Market Coverage** – SPX, IXIC, DJI, Russell 2000, major sector ETFs, volatility ETNs, treasuries, global indices, metals, energy, and crypto pairs are all synchronized through SMA campaigns.
2. **Timeframes** – SMA outfits operate from tick-level data through quarterly aggregates. Institutional control hinges on cross-timeframe alignment, so every tool here treats multi-timeframe coherence as a first-class constraint.
3. **Operational Definitions** – Precision Buying Algorithms, Automated Short Orders, Optimized Buying Algorithms, Singular Point Hard Stops, and Magnetized Buying Programs share common primitives, noted throughout the docs and implementation.
4. **Transparency Objective** – Rather than highlight supposed inefficiencies, the repository proves that tightly coordinated SMA selections are the mechanism by which markets remain “efficient” for those with privileged access.

Readers should use this document as a map of the repository. Each directory expands on one portion of the overall thesis, from raw data and tooling to real-time documentation threads.
