# Market Impact Charts

This folder houses visual narratives that demonstrate how SMA outfits manifest as observable market events. Recommended chart types include:

- **Multi-SMA Overlays:** Plotting multiple outfits on the same price series to reveal synchronization between indices and leading equities.
- **Volatility Echoes:** Visualizing how VIX/SVIX reacts when core outfits flip from positive to negative states.
- **Liquidity Footprints:** Annotating dark-pool inferred executions that coincide with singular point hard stop breaches.

Each chart should include:
1. **Data Provenance:** Source feed, timeframe, and outfit specification.
2. **Narrative Caption:** A concise explanation linking the visual to a documented operation.
3. **Regulatory Context:** Notes on whether the event triggered disclosures, halts, or observable compliance artifacts.

Use vector-friendly formats (SVG/PNG) so charts remain crisp within GitHub Pages and downstream reports. EOF
