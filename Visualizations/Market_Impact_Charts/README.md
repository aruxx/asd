# Market Impact Charts

Visualizations in this folder illustrate how SMA outfits orchestrate liquidity in real time:

- **Midterm Trend Panels** – Align SPX 30m 10/50/200 with IXIC 20m 20/100/250 and DJI 15m 30/60/90/300/600/900 to show systemic pivots.
- **Volatility Shock Maps** – Overlay VIX state changes when SMA slope reversals occur.
- **Cross-Asset Ripples** – Show DXY, gold, treasuries, and crypto responses lagging or leading major SMA triggers.

Each chart is annotated with precise timestamps, outfits engaged, and links back to the Real_Time_Operations threads that captured the events live.
