# Simulation Models

Simulation assets demonstrate how SMA outfits behave under hypothetical shocks:

- **Volatility Bursts** – Stress tests showing how quickly magnetized orders re-anchor price.
- **Liquidity Vacuums** – Model scenarios where dark pools absorb flow before public markets react.
- **Timeframe Drift** – Explore how misaligned timeframe stacks degrade signal quality and what recalibration is required.

The same models can feed the "Active Programs" monitor in the UI to compare live data with simulated baselines.
