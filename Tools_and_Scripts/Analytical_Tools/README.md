# Analytical Tools

This directory will host scripts and notebooks that:

- Pull historical or real-time OHLCV data from any of the supported APIs.
- Compute SMA stacks up to 999 periods across dozens of timeframes in parallel.
- Detect crossovers, slope reversals, volatility overrides, and harmonic confirmations.
- Export signals into JSON, CSV, or streaming WebSocket payloads for downstream automation.

The web UI mirrors these capabilities inside the browser; contributors can extend them here for server-side batch workflows.
