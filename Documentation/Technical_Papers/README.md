# Technical Papers

Whitepapers and long-form technical briefs live here. Each document includes:

- **Problem Framing** – The specific SMA outfit or market behavior under examination.
- **Data Appendix** – Sources, cleansing notes, and reproducibility hashes.
- **Algorithmic Detail** – Mathematical derivations, pseudo-code, and references to the open-source tools in this repo.
- **Compliance Statement** – Documentation of regulatory considerations when publishing sensitive workflows.
